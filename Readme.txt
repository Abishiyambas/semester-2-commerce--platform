To successfully run the projects, ensure the following steps are completed:

For the PIM project:

- Create a file named Credentials.txt if it does not exist in the project root.

- Enter the User ID and Password for the database in the format: someUser somePassword


For the PIM.Test project:

- Copy the same Credentials.txt file as above.

- Place it in the root of the PIM.Test project.

- Additionally, copy this file into the root of the SHOP project to enable the integration tests.
